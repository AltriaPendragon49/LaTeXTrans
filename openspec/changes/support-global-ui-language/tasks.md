# 实施任务

1. **前端 i18n 基础设置**:
    - [ ] 安装多语言国际化库（如 `i18next`, `react-i18next`）。
    - [ ] 在 `src/i18n.ts` 中初始化 i18n 配置。
    - [ ] 创建 `src/locales/` 目录并配置 8 种语言的初始化翻译 JSON 文件。
2. **全局 UI 语言选择器组件**:
    - [ ] 根据 `ui-ux-pro-max` 的原则，开发一个 `LanguageSelector` React 组件，具备优雅的悬浮效果、良好的可访问性和键盘导航支持。
    - [ ] 将该组件集成到应用的全局布局（Layout/Header/Sidebar）中。
3. **状态管理和持久化**:
    - [ ] 将语言切换器连接到 i18n 的更改方法，确保选择语言时页面元素实时更新。
    - [ ] 确保通过本地存储（localStorage 或现有的 store）持久化选择的界面语言设置，使得页面刷新后也能维持。
4. **前端文本替换**:
    - [ ] 遍历如 `Dashboard`, `Settings`, `History`, `FormattingPanel` 等主要组件中的硬编码中文字符串，使用翻译 Hook 替换（如 `useTranslation` 的 `t()` 函数）。
5. **UI 设计验证**:
    - [ ] 验证语言选择器在 Light 模式和 Dark 模式下是否有清晰可见的对比度和合适的悬浮反馈效果。
    - [ ] 补充缺失的词汇，确保主流页面在 8 国语言下的布局不会因文本过长而破损。
