# 提案：全局 UI 语言多语言支持

## 问题描述
目前应用支持在后端翻译配置中选择 8 种语言（英语、中文、日语、韩语、德语、法语、西班牙语、俄语）进行文档翻译，但前端用户界面（UI）是静态的，主要显示中文。用户需要一种方法在前端全局切换界面的显示语言，使其符合当前可选的 8 国语言配置。

## 解决方案
我们提议在前端添加一个全局语言选择器，支持在现有的 8 种语言中进行切换。
- **语言范围**：遵循系统当前的配置数组（en, zh, ja, ko, de, fr, es, ru）。
- **设计规范**：使用 `ui-ux-pro-max` 技能提供的优雅（elegant）选择器设计标准，支持深浅色模式适配。
- **技术实现**：引入国际化（i18n）支持（如 `react-i18next`），在顶部导航栏或侧边栏位置提供界面语言切换组件，切换时全局生效，并持久化用户的语言偏好。
