# Translation Kernel Archive Status

As of the May 9, 2026 production cleanup, the current production translation kernel is:

- backend-owned `origin_cli_parity`
- the thin parity LangGraph wrapper
- the bounded parity health branch in the compiler

Archived changes that describe controlled repair, hard-freeze orchestration, structure guard, ultimate downgrade, post-compile target-language fallback, residual-English fallback, compilation diagnostic nodes, or other modern-kernel enhancement branches are historical records only. They are not current implementation truth and must not be used as active design guidance unless a future approved OpenSpec change reintroduces them with production code.

The current source of truth is:

- `openspec/specs/latex-translation-core/spec.md`
- `openspec/specs/translation-orchestration/spec.md`
