# Change: Stitch Frontend Rebuild

## Why
The frontend required a structural and visual rebuild to align with the approved Stitch designs across Community Feed, Community Conversation, Paper Detail, and Tools Hub.

## What Changes
- Rebuilt Community Feed with compact launch-first interaction.
- Rebuilt Community Conversation with refined chat workspace and input ergonomics.
- Rebuilt Paper Detail with maximized reader-first layout and integrated assistant workspace.
- Reorganized utility workflows into the Tools Hub functional core.
- Updated shared app shell and sidebar behaviors for consistent navigation and settings placement.

## Impact
- Affected specs: `community-paper-discovery-ui`, `community-public-read-experience`, `web-ui`
- Affected code: `frontend/src/*` layout, page composition, navigation, and associated UI tests.
