# Why
- Day 5 is the first milestone gate, not a feature grab bag.
- The Week 1 source plan defines success as one stable chain from paper submission through translation, preview, and download.
- A dedicated stabilization change keeps the roadmap honest and prevents Day 6-10 work from hiding unresolved main-path issues.

## What Changes
- Define the Week 1 end-to-end acceptance slice for submit, intake, detail, translate, processing, preview, and download.
- Define the minimum UI state handling required to demo the main chain reliably.
- Define the close-out rule for moving from Week 1 into interaction and moderation work.

## Impact
- Adds capability `community-week1-readiness`.
- Depends on `add-community-day-04-paper-translation-preview-download`.
- Acts as the release gate for the second half of the 10-day plan.
