# 更改：添加基于 Web 的 MVP 前端界面

## 为什么

此更改为 LaTeX 翻译平台构建了面向用户的前端。后端 API 端点已经就位（来自“add-web-mvp-platform”），我们现在需要：

- 适合非技术用户的现代、易于访问的网络界面
- 翻译进度实时视觉反馈
- 直观的文件上传和 arXiv ID 输入机制
- 翻译后的 PDF 和源文件的无缝下载体验

该前端通过提供用户和翻译引擎之间的“最后一英里”连接来完善 MVP。

## 有何变化

- **React应用程序**：使用Vite + React 18的现代单页应用程序
- **UI 组件**：文件上传、arXiv 输入、进度跟踪器、下载按钮
- **样式**：TailwindCSS 实现响应式、现代设计
- **API集成**：基于Axios的客户端连接到FastAPI后端
- **集成测试**：完整翻译工作流程的端到端验证

**依赖关系**： 
- **要求**：`add-web-mvp-platform`必须先完成更改（后端 API 必须可用）

## 影响

### 受影响的规格
- **新**：`web-ui`- React前端用户界面规范
- **扩展**：`web-api`- 使用后端更改中定义的端点

### 受影响的代码
- 新目录：`frontend/`（整个 React 应用程序）
- 集成：后端 API 端点位于 `http://localhost:8000`
- 测试：跨浏览器验证和端到端工作流程测试

## 时间轴
1周（后端完成后）

## 验证标准
- ✅ 前端可通过 http://localhost:5173 访问
- ✅ 文件上传 UI 功能，具有拖放功能
- ✅ arXiv ID 输入验证并触发下载
- ✅ 进度条通过轮询实时更新
- ✅ 完成后出现下载按钮
- ✅ 跨浏览器兼容（Chrome、Firefox、Edge）
- ✅ 端到端工作流程测试通过（上传→翻译→下载）
