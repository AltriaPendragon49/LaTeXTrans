## Context
当前社区首页论文卡片在 hover 时会触发一个位于卡片左侧的独立放大镜式 inspector。该 inspector 会根据鼠标位置实时计算锚点、偏移量与局部裁切区域，形成“局部高倍检查”效果。新的需求是不再保留这个独立放大镜，而是让用户悬停时直接看到原卡片本体被放大，且保持整页静态预览。

## Goals / Non-Goals
- Goals:
  - 悬停时放大当前卡片本体，而不是渲染独立放大镜浮层
  - 保持第一页完整可见，避免局部裁切追踪
  - 清理旧放大镜相关状态、事件与测试
- Non-Goals:
  - 不修改论文详情页的 PDF 阅读体验
  - 不引入新的弹出层式大预览面板
  - 不改变首页卡片的基础数据源与双缩略图布局

## Decisions
- Decision: 首页卡片 hover 仅通过卡片本体的 scale、阴影和层级提升来表达“放大”，不再渲染 inspector 容器。
- Decision: 预览内容继续使用现有缩略图第一页图像，保持整页 fit，不再根据鼠标位置加载或平移局部高分辨率图。
- Decision: `pdf-hover-preview.ts` 若只服务于旧放大镜流程，则在实现阶段删除；若仍需保留最小公共能力，则改造成不带放大镜语义的实现。
- Alternatives considered:
  - 保留独立浮层但展示整页静态大图：仍保留了额外浮层，不符合“原卡片放大”的目标。
  - 继续做局部镜头但弱化动画：仍然保留了用户明确不要的交互模型。

## Risks / Trade-offs
- 卡片 hover 放大后可能遮挡相邻卡片，需要通过层级和 transform 控制减少布局干扰。
- 移除高分辨率局部预览后，查看细节能力会降低，但这符合当前简化交互的产品目标。

## Migration Plan
1. 先更新规范与测试预期。
2. 再替换首页卡片 hover 行为并删除旧 inspector 逻辑。
3. 最后清理废弃服务和命名。
