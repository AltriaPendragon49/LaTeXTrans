## 5. 当前正式公网链路

当前正式公网访问方式是：

```text
https://latextrans.niutrans.com
  -> Cloudflare Pages
  -> 同源 /api/*
  -> Pages Functions
  -> https://api.latextrans.online
  -> Cloudflare Named Tunnel
  -> 受控生产主机
  -> 127.0.0.1:9001
```

说明：

- 正式方案不是“本机 Nginx 直接作为前端”
- 正式方案也不是“临时 Cloudflare Quick Tunnel”
- 当前正式方案是 Pages + Functions + Named Tunnel

## 6. 当前生产存储策略

当前生产环境使用：

```env
STORAGE_BACKEND_MODE=cos
```

含义：

- COS 是正式持久化存储
- 本地磁盘只承担临时缓存、任务运行输出和开发回退

## 7. 当前 PDF 预览相关状态

### 7.1 英文原文 PDF

当前已确认：

- 原文 PDF 支持 `Range`
- 首屏读取不再总是走整文件返回

### 7.2 中文译文 PDF

当前已确认：

- 译文 PDF 预览走第一方 API inline 代理
- 下载走签名下载

原因是 COS 默认直链不适合作为稳定 iframe 预览方案。
